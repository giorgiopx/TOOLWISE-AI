# Launch checklist

- [ ] Create a GitHub repository and upload the project root.
- [ ] Import repository into Netlify; build command `npm run build`, publish directory `dist`.
- [ ] Confirm the temporary Netlify URL works and inspect mobile layout.
- [ ] Choose domain after checking both availability and renewal price. Netlify can register many TLDs, but availability and supported extensions must be checked in its UI.
- [ ] Update `site` in `astro.config.mjs` and `public/robots.txt` to the chosen canonical domain.
- [ ] Replace placeholder contact email and finish privacy/cookie/consent requirements.
- [ ] Review and approve articles individually; set `draft: false` and `reviewed: true` only when ready.
- [ ] Verify every external product claim, price, affiliate link and disclosure.
- [ ] Add Search Console and submit the generated sitemap after the real domain is live.
- [ ] Apply for AdSense when the site has useful, complete content and all policy pages are ready. Add only the actual code supplied by AdSense.
